# Smart-Travel-Planner

A simple application that helps users plan trips efficiently with features like notes, flashcards, quizzes, tasks, and code lab assistance.

## Features
- Notes taking (autosave)
- Flashcards for quick revision
- Quiz functionality
- Planner for scheduling
- Code Lab for development tasks
